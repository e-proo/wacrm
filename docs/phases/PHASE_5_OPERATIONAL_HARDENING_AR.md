# المرحلة الخامسة — التقوية التشغيلية والمراقبة

> **الحالة:** مكتملة برمجياً، بدون commit جديد حتى تأكيد المستخدم.

هذه مرحلة تشغيلية إضافية بعد المراحل الأربع الأساسية. هدفها تجهيز النظام للمراقبة والتشخيص في بيئة متعددة النسخ، بدون إنشاء نظام محاسبي أو إضافة أرصدة.

## ما تم تجهيزه

### Migration 056

أضيفت الجداول:

- `ai_agent_tool_call_attempts`: سجل كل محاولة أداة مع الوكيل والإصدار والدورة والحالة والمدة وكود الخطأ، بدون حفظ أسرار أو نصوص كاملة.
- `ai_agent_rate_limit_overrides`: حدود دقيقة/يومية/شهرية للحساب أو الوكيل، مع RLS وصلاحية admin+.
- `ai_reconciliation_jobs`: سجل مهام الاسترداد والتسوية التشغيلية مع `lease_expires_at` و`claimed_by` و`attempt_count`.

تم استخدام `ai_usage_log` الموجود مسبقاً بدلاً من إنشاء جدول استخدام مكرر.

### المقاييس التشغيلية

أضيف:

```text
src/lib/ai/runtime/operational-metrics.ts
GET /api/ai-metrics
```

يعيد لكل حساب:

- عدد استدعاءات الذكاء.
- prompt tokens وcompletion tokens وtotal tokens.
- عدد التشغيلات حسب الحالة.
- عدد استدعاءات كل أداة وحالات فشلها.
- آخر الأخطاء المنقحة.

الفترة الافتراضية آخر 30 يوماً، ويمكن تمرير `?since=ISO_TIMESTAMP`.

### واجهة المراقبة

أضيف تبويب **المراقبة التشغيلية** في `/agents` ويعرض:

- بطاقات استخدام الرموز.
- حالات التشغيل.
- استدعاءات الأدوات وفشلها.
- آخر الأخطاء.

الواجهة admin+ فقط.

## الضوابط

- كل الاستعلامات مقيدة بـ `account_id`.
- سجلات الأداة لا تحتوي على secret أو prompt كامل.
- لا يوجد service role في العميل.
- سياسات RLS تمنع viewer من قراءة بيانات التشغيل الحساسة.
- الجداول قابلة للاسترداد عبر lease ولا تعتمد على بقاء HTTP مفتوحاً.

## ما يجب فعله في بيئة Supabase

1. تطبيق `056_operational_hardening.sql` في staging.
2. فحص RLS بحساب admin وحساب viewer وحساب من tenant آخر.
3. إضافة scheduler يستدعي sweep للـ runs والمهام ذات lease منتهٍ.
4. ضبط تنبيهات لـ queued runs القديمة، وارتفاع فشل الأدوات، وبلوغ حدود المعدل.
5. عدم تطبيق down migration حذفي في الإنتاج.

## الحالة

الكود المحلي وواجهة المراقبة جاهزان. تطبيق Migration 056 في Supabase، واختبارات RLS والـ scheduler هي خطوات تشغيلية قبل الإطلاق، وليست commit تلقائية.
